## 1. Vision & Executive Summary

Mục tiêu là đưa nền tảng quản lý dự án **Vira** từ môi trường cục bộ (Localhost) lên hạ tầng đám mây công cộng **Amazon Web Services (AWS)** theo tiêu chuẩn công nghiệp (Production-ready), bảo mật cao, tối ưu tối đa chi phí Free Tier và được tự động hóa hoàn toàn thông qua **GitHub Actions CI/CD**.

### Giá trị đạt được
- **Học tập & Thực hành**: Hiểu cặn kẽ bản chất mạng VPC, EC2, S3, CloudFront, ACM SSL, DNS Resolution, Docker và CI/CD.
- **Hiệu năng & Chi phí**: Frontend tải siêu nhanh toàn cầu qua AWS CloudFront Edge Locations; Backend chạy ổn định, an toàn; Chi phí thực tế gần như **$0/tháng** (hoặc cực kỳ thấp dưới $3) trong thời gian Free Tier.
- **Bảo mật**: HTTPS mã hóa toàn trình (Let's Encrypt + AWS Certificate Manager), bảo vệ cổng database, tách biệt biến môi trường nhạy cảm (`.env`).

## 4. Thành phần & Thiết kế Chi tiết

### 4.1. Frontend (S3 + CloudFront)
- **Quy trình Build**: `npm run build` tạo ra thư mục tĩnh `dist/` chứa `index.html`, JS chunks, CSS và assets.
- **S3 Bucket**: Đặt ở chế độ Private (bảo mật), chỉ cho phép AWS CloudFront truy cập thông qua **Origin Access Control (OAC)**.
- **CloudFront CDN**:
  - Tự động nén Gzip/Brotli giúp tải trang nhanh.
  - Cấu hình **Custom Error Response (403/404 -> /index.html với mã 200)** để hỗ trợ React Router SPA không bị lỗi khi người dùng F5 tải lại trang.
  - Tích hợp SSL Certificate miễn phí từ **AWS ACM** (vùng `us-east-1`).

### 4.2. Backend & Data Layer (EC2 Dockerized)
- **Máy chủ EC2**:
  - Hệ điều hành: Ubuntu 24.04 LTS (Hỗ trợ lâu dài, cộng đồng lớn).
  - Cấu hình: `t3.micro` hoặc `t4g.small` (Free tier hoặc chi phí thấp).
  - Cấu hình Swap RAM: Tạo 2GB Swap Memory để Spring Boot chạy Java 21 mượt mà, không bao giờ bị tràn RAM (OOM Killer).
- **Reverse Proxy**: Dùng **Caddy Server** hoặc **Nginx + Certbot**:
  - Caddy được khuyên dùng hàng đầu hiện nay vì: Tự động xin và gia hạn chứng chỉ SSL Let's Encrypt 100% tự động, cấu hình chỉ cần 5 dòng, siêu nhẹ.
- **Docker Compose Production**:
  - `vira-api`: Đóng gói ứng dụng Spring Boot, chỉ mở port nội bộ cho Reverse Proxy.
  - `vira-mysql`: Lưu trữ dữ liệu với Persistent Volume trên ổ cứng EBS của EC2. Không mở port 3306 ra ngoài Internet (Security Group chỉ cho phép truy cập nội bộ).
  - `vira-redis`: Dùng cho Rate Limiter và Cache.
- **File Uploads**: Tạm thời ánh xạ volume cục bộ `/data/uploads` trên EC2, sẵn sàng module tích hợp đẩy trực tiếp lên S3 bucket trong tương lai.

### 4.3. Bảo mật (Security Best Practices)
1. **AWS Budget & Billing Alert**: Thiết lập ngay cảnh báo nếu chi phí phát sinh vượt quá $1 hoặc $3/tháng để bảo vệ ví tiền của bạn.
2. **EC2 Security Group**:
   - Chỉ mở port `22` (SSH - giới hạn IP cá nhân nếu có thể hoặc dùng SSH Key).
   - Mở port `80` (HTTP) và `443` (HTTPS) cho toàn thế giới để gọi API.
   - Tuyệt đối đóng các port `8080`, `3306`, `6379` khỏi Internet.
3. **CORS & Environment Variables**:
   - Cập nhật CORS Backend cho phép origin: `https://daoductam.dpdns.org`.
   - Toàn bộ mật khẩu DB, JWT Secret, Mail credentials được quản lý qua file `.env` trên máy chủ và GitHub Repository Secrets, không bao giờ commit lên git.

## 5. Kế hoạch CI/CD (GitHub Actions Pipeline)

Hai luồng công việc tự động:
1. **Frontend CI/CD (`.github/workflows/deploy-frontend.yml`)**:
   - Kích hoạt khi có commit vào nhánh `main` (thư mục frontend).
   - Chạy `npm ci` -> `npm run build` -> Đẩy files lên S3 -> Xóa cache CloudFront (`aws cloudfront create-invalidation`).
2. **Backend CI/CD (`.github/workflows/deploy-backend.yml`)**:
   - Kích hoạt khi có commit vào nhánh `main` (thư mục backend).
   - Build Docker image -> Đẩy lên Docker Hub hoặc đóng gói -> SSH vào EC2 -> `docker compose pull && docker compose up -d`.

## 6. Lộ trình Triển khai Thực tế (Roadmap)

- **Giai đoạn 1: Chuẩn bị & Quản lý Chi phí AWS**
  - Đăng nhập AWS Console, cài đặt AWS Budget Alert ($3/tháng).
  - Tạo IAM User có quyền triển khai, bật xác thực 2 lớp (MFA).
- **Giai đoạn 2: Khởi tạo Hạ tầng Backend (EC2 & Security)**
  - Tạo EC2 Instance (Ubuntu 24.04), gắn Elastic IP (IP tĩnh).
  - Cấu hình Swap RAM 2GB và cài Docker Engine + Docker Compose.
- **Giai đoạn 3: Cấu hình Tên miền (DNS) & Caddy SSL**
  - Trỏ subdomain `api.daoductam.dpdns.org` về Elastic IP của EC2.
  - Thiết lập Caddy để tự động cấp chứng chỉ SSL HTTPS.
- **Giai đoạn 4: Triển khai Backend lên EC2 & Kiểm thử API**
  - Chuẩn bị file `compose.prod.yaml` và cấu hình biến môi trường production.
  - Khởi chạy các container và kiểm tra `https://api.daoductam.dpdns.org/actuator/health`.
- **Giai đoạn 5: Triển khai Frontend lên S3 & CloudFront**
  - Tạo S3 Bucket, thiết lập CloudFront Distribution + ACM Certificate cho `daoductam.dpdns.org`.
  - Cập nhật API Base URL ở frontend trỏ về backend production.
  - Build và đồng bộ lên S3.
- **Giai đoạn 6: Tự động hóa với GitHub Actions (CI/CD)**
  - Cấu hình GitHub Secrets (`AWS_ACCESS_KEY_ID`, `EC2_SSH_KEY`, etc.).
  - Tạo workflow CI/CD để tự động deploy khi push code.
